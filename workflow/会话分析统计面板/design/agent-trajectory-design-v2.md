# 轨迹泳道 v2：收拢交互 + 泳道内明细 + 第一性原理补盲

取代 agent-trajectory-design.md（ar_01M5C2MDZ5000D571EWBPNCG2V）。用户 2026-10-20
第二轮意见：泳道与排行默认收拢只出主代理；泳道点击展开成折线图看清任意时刻的
用量与上下文；并从第一性原理补齐没被可视化的信息。

## 第一性原理：盯多智能体会话的人在问什么

| 问题 | 数据在不在 | v1 可视化了吗 | v2 怎么补 |
| --- | --- | --- | --- |
| token 去哪了（含缓存占比） | 在（毛输入/缓存列） | 部分（排行有毛输入） | 排行加效率列 |
| 烧了多少 vs 产出多少 | 在（output/input） | 没可视化 | 效率比列 + 合计行 |
| 谁在干活谁在空转（并行节奏） | 在（子代理区间） | 只有峰值数字 | 并行度随时间曲线（浪涌可见） |
| 什么时候转折（模型切换/压缩） | 在（turn_context 时间戳） | 没可视化 | 跨泳道模型切换参考线（06:36 → gpt-6-astra） |
| 主代理在等谁（编排阻塞） | 近似（wait_agent 时间戳） | 没可视化 | 主泳道等待区间阴影（近似口径，标注） |
| 每个代理自己的生命周期 | 在（子 rollout 逐调用） | 没可视化 | 泳道点击展开迷你图（见下） |

## 选定方案（v2 增量）

1. **收拢默认**：泳道区默认只有主代理一条 + 「子代理 N 条 · 合计 X · 峰值并行
   Y ▸」汇总按钮；开销排行默认收起（合计行 + 最高一条 + 展开按钮）。
2. **泳道点击展开明细**（2026-10-20 第三轮修订）：任一泳道（含主代理）点击后
   内嵌展开**一张合并图**——面积=毛输入（模型色）、折线=上下文占用（含压缩回
   落，紫色），双归一化叠加；整块高度压在折叠泳道行高的 4 倍以内（第四轮修订：
   图高 46px、实测整块约为行高的 2 倍；线宽 0.7/0.9 并加 non-scaling-stroke，
   防 preserveAspectRatio=none 拉伸把线变粗）。明细图与泳道轨道共用同一三列网格
   （标签 200px | 轨道 1fr | 折钮 22px），绘图区与所有泳道像素级左右对齐、彼
   此对齐；时间读数（第五轮修订）：不在明细下另设刻度行（与底部共享时间轴
   重复），明细 SVG 内只留 10 分钟细网格线（主刻度略浓），时刻由底部共享轴
   （像素对齐）与悬停游标读数（时刻 · 输入 · 上下文）承担；图内带模型切换参
   考线；再点收起。明细 DOM 挂在泳道节点内，收起
   子代理组时随泳道整体移除，无残留。数据来自该代理 rollout 的逐调用解析
   （复用 phase A 生命周期解析器，按代理缩微渲染）。
3. **补盲可视化**：
   - 效率比：排行新增 输出/毛输入 列（本例 worker 合计约 0.35%，一眼看出
     「烧 88M 产出 0.3M」）；缓存占比进悬停明细。
   - 并行度曲线：汇总区一条随时间的活跃子代理数面积图（本例 06:48–06:56 浪涌
     到 6 可见）。
   - 模型切换参考线：跨泳道竖线 + 标签（派发模型切换点）。
   - 等待区间：主泳道上 spawn 之后到 wait 完成之间的阴影段（近似口径，实现时
     用 wait_agent 调用时间戳界定并标注「等待中（估算）」）。

可交互原型：`mockups/agent-trajectory-v2.html`（真实数据；默认收拢/展开、泳道
明细、排行展开、并行度曲线、模型切换线、悬停明细、双语双主题）。

## 沿用 v1 的决定

子代理发现（thread_spawn.parent_thread_id 精确 + guardian 按窗标注估算）、
>30 泳道截断、数据命令扩展（agents/orchestration 数组）、非 Codex 源第一版
只显示主代理泳道。用户未回复的三个未决问题按推荐执行：guardian 纳入并标注
估算、泳道按派发时间排序、拖选缩放留待后续迭代。

## 影响面（相对 v1 增量）

前端约 +200 行（收拢态、明细展开渲染复用迷你图组件、并行度曲线、参考线）；
Rust 侧不变（agents 数组已含 per-agent 逐调用解析所需的全部输入，明细展开时
按需再调一次 get_session_lifecycle(id=子代理) 即可，子代理也是会话，命令天然
可复用——这是把子代理建模为「会话」的直接红利）。

## 怎么算做对

- 默认打开：只有主代理泳道 + KPI + 并行度曲线，一屏能看完骨架。
- 展开 worker #10（gpt-6-astra，14.5M）：迷你图与该子 rollout 逐调用数据一致。
- 06:36 参考线之后的 worker 泳道全部为 gpt-6-astra 色。
- 收起排行后再展开，27 行含合计与效率列。
